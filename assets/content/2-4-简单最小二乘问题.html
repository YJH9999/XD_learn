2.4 简单最小二乘问题

问题来源定义

当 \(Ax=b\) 无解（\(R(A)<R(A,b)\)，数据点不在一条直线/平面上）时，转而求使残差平方和最小的 \(x\)：

$$\min_{x}\ \|Ax-b\|^2$$

这个最优解 \(x^*\) 称为最小二乘解。几何解释：把 \(A\) 的列向量张成的子空间记为 \(S=R(A)\)，\(Ax\in S\)；最小二乘就是找 \(S\) 中离 \(b\) 最近的点 \(Ax^*\)——即 \(Ax^*\) 是 \(b\) 在 \(S\) 上的正交投影，残差 \(b-Ax^*\perp S\)。

正规方程定理

$$\boxed{\ A^{\top}Ax=A^{\top}b\ }\qquad \text{当 } R(A)=n \text{（列满秩）时唯一解 } x^*=(A^{\top}A)^{-1}A^{\top}b$$
证明正规方程的推导与唯一性

正交条件：残差 \(b-Ax\) 垂直于子空间 \(S=R(A)\) ⟺ 它与 \(S\) 的每一列 \(A_j\) 正交 ⟺ \(A^{\top}(b-Ax)=0\)。写开就是 \(A^{\top}Ax=A^{\top}b\)——正规方程。

为什么最优：对任意 \(x\)，把 \(Ax\) 分解为 \(Ax^*+\)（\(S\) 内分量），则 \(\|Ax-b\|^2=\|Ax-Ax^*\|^2+\|Ax^*-b\|^2\ge\|Ax^*-b\|^2\)（勾股定理，正交分解），等号当且仅当 \(Ax=Ax^*\)。

列满秩 ⇒ 唯一：\(R(A^{\top}A)=R(A)=n\) 用秩不等式链：\(A^{\top}Ax=0\Rightarrow x^{\top}A^{\top}Ax=0\Rightarrow\|Ax\|^2=0\Rightarrow Ax=0\Rightarrow x=0\)（列满秩时齐次只有零解），故 \(A^{\top}A\) 可逆。

推导要点：\(b-Ax^*\) 与 \(S=R(A)\) 正交 ⟺ 与 \(A\) 的每一列正交 ⟺ \(A^{\top}(b-Ax)=0\)，即 \(A^{\top}Ax=A^{\top}b\)。列满秩时 \(R(A^{\top}A)=R(A)=n\)，故有唯一解。

例 19用最小二乘拟合直线

用直线 \(y=a+bx\) 拟合点 \((0,1),(1,1),(2,3)\)，求 \(a,b\) 的最小二乘解。

写成超定方程组 \(Ax=b\)：\(A=\begin{pmatrix}1&0\\1&1\\1&2\end{pmatrix}\)，\(b=(1,1,3)^{\top}\)（三式 \(a+bx=y_i\)，但三点不共线，无精确解）。

$$A^{\top}A=\begin{pmatrix}3&3\\3&5\end{pmatrix},\qquad A^{\top}b=\begin{pmatrix}5\\7\end{pmatrix}$$

解正规方程 \(\begin{cases}3a+3b=5\\3a+5b=7\end{cases}\) 得 \(b=1,\ a=\frac23\)。拟合直线 \(y=\frac23+x\)，残差平方和 \(\|Ax^*-b\|^2=(\tfrac23-1)^2+(\tfrac53-1)^2+(\tfrac83-3)^2=\tfrac13\)。

点评：最小二乘 = "无解方程组的最佳折中"，回归分析的理论地基；考试常给 3~4 个数据点要求拟 \(y=a+bx\) 或 \(y=a+bx+cx^2\)。

拓展 · 可能考考前加分

① 投影矩阵的两大性质（小证明）：\(P=A(A^{\top}A)^{-1}A^{\top}\) 满足 \(P^{\top}=P\)（\((A^{\top}A)^{-1}\) 对称）与 \(P^2=P\)（中间 \(A^{\top}A\) 约掉）。幂等对称矩阵 = 正交投影算子。

② 正规方程的几何语言：\(A^{\top}(b-Ax^*)=0\) 说明残差 \(b-Ax^*\) 与 \(A\) 的每一列正交，即 \(b\) 的最小二乘解 = 把 \(b\) 正交投影到列空间 \(R(A)\)。

③ 直线拟合的落地形式：拟合 \(y=at+b\) 时 \(A\) 的两列是 \((x_1,\dots,x_n)^{\top}\) 和 \((1,\dots,1)^{\top}\)，未知量 \(z=(a,b)^{\top}\)——数据点个数为 \(n\)，正规方程是 \(2\times2\) 的。

拓展 · 常用技巧技巧归纳

① 存在性与唯一性：正规方程 \(A^{\top}Ax=A^{\top}b\) 恒有解；解唯一 \(\iff R(A)=\) 列数（\(A\) 列无关）。

② \(A^{\top}A\) 可逆判据：\(A\) 列无关 \(\iff A^{\top}A\) 可逆（实矩阵 \(R(A^{\top}A)=R(A)\)），此时唯一解 \(x=(A^{\top}A)^{-1}A^{\top}b\)。

③ 多解时的通解：\(A\) 列相关时最小二乘解不唯一，通解 = 任一特解 + \(\ker A\)；数据拟合题选范数最小的一个。

④ 三点共线的行列式判据：平面上三点 \((x_i,y_i)\) 共线 \(\iff\begin{vmatrix}1&x_1&y_1\\1&x_2&y_2\\1&x_3&y_3\end{vmatrix}=0\)——"拟合直线是否存在"的快速判断。
