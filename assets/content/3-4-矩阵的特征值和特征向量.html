3.4 矩阵的特征值和特征向量

定义与求法定义

$$Ax=\lambda x\ (x\ne 0)\qquad \Longrightarrow\qquad |A-\lambda E|=0\ \text{（特征方程）}$$

求特征向量：把 \(\lambda_i\) 代入 \((A-\lambda_iE)x=0\)，其非零解即属于 \(\lambda_i\) 的特征向量。同一特征值的特征向量的非零线性组合仍是该特征值的特征向量；不同特征值对应的特征向量之和不是特征向量。

两大速算公式高频考点

$$\lambda_1+\cdots+\lambda_n=\operatorname{tr}(A)=a_{11}+\cdots+a_{nn}\qquad \lambda_1\lambda_2\cdots\lambda_n=|A|$$
证明迹与行列式 = 特征值的和与积

特征多项式 \(f(\lambda)=|A-\lambda E|\) 展开后是 \(\lambda\) 的 \(n\) 次多项式：\(f(\lambda)=(\lambda_1-\lambda)\cdots(\lambda_n-\lambda)\)（\(\lambda_i\) 为根）。

积：令 \(\lambda=0\)：\(f(0)=|A|=\lambda_1\lambda_2\cdots\lambda_n\)。

和：比较 \(\lambda^{n-1}\) 的系数。左端 \(|A-\lambda E|\) 中含 \(\lambda^{n-1}\) 的项只能取自对角元之积 \(\prod(a_{ii}-\lambda)\)（其他列选了非对角元会同时用掉两行且至多贡献 \(\lambda^{n-2}\)），其 \(\lambda^{n-1}\) 系数为 \((-1)^{n-1}\operatorname{tr}A\)；右端为 \((-1)^{n-1}\sum\lambda_i\)。比较即得 \(\operatorname{tr}A=\sum\lambda_i\)。

\(f(A)x=f(\lambda)x\) 与 \(A^{*}x=\frac{|A|}{\lambda}x\)：前者反复用 \(A^mx=\lambda^mx\)（归纳）；后者由 \(A^{-1}x=\lambda^{-1}x\)（\(Ax=\lambda x\) 两边左乘 \(A^{-1}\)）与 \(A^{*}=|A|A^{-1}\) 得到。

推论：\(A\) 可逆 ⟺ 所有特征值非零；0 是特征值 ⟺ \(|A|=0\)。利用迹与行列式"凑"特征值（已知部分求剩余）是填空题常客。

重要性质清单定理

  • \(A^mx=\lambda^m x\)；\(f(A)x=f(\lambda)x\)（\(f\) 为多项式）；\(A^{-1}x=\lambda^{-1}x\)；\(A^{*}x=\dfrac{|A|}{\lambda}x\)。
  • 不同特征值的特征向量线性无关；同一特征值的特征向量中线性无关的个数 ≤ 重数。
  • \(A^{\top}\) 与 \(A\) 特征值相同（但特征向量一般不同）。
  • 若 \(f(A)=O\)，则 \(A\) 的每个特征值满足 \(f(\lambda)=0\)（如 \(A^2=A\Rightarrow\lambda\in\{0,1\}\)）。
  • 分块矩阵 \(\begin{pmatrix}A&\\&B\end{pmatrix}\) 的特征值 = \(A\) 的 ∪ \(B\) 的特征值。
  • \(k\) 重特征值的线性无关特征向量个数 ≤ \(k\)；\(R(A-\lambda_0E)=n-k\) 时恰有 \(k\) 个。
例 23抽象矩阵的特征值

设 \(A^2=A\)（幂等），证明 \(A\) 的特征值只能是 0 或 1；又若 \(R(A)=r\)，写出 \(|A+E|\)。

由 \(Ax=\lambda x\) 得 \(A^2x=\lambda^2x\)，又 \(A^2x=Ax=\lambda x\)，故 \(\lambda^2=\lambda\)，\(\lambda\in\{0,1\}\)。幂等矩阵可对角化（\(R(A-\lambda E)\) 检验成立），故 0 出现 \(n-r\) 次、1 出现 \(r\) 次：

$$|A+E|=(0+1)^{n-r}\cdot(1+1)^{r}=2^{r}$$

点评："特征值多多项式 + 可对角化 + 行列式 = 特征值连乘"三件套组合，是抽象行列式题的标准解法。更直接的一招：\(A+E\) 的特征值 = \(0+1,1+1\) 即 \(1,2\)。

例 24含参数特征值反求参数

设 \(A=\begin{pmatrix}a&1\\1&a\end{pmatrix}\) 有特征值 \(0\) 与 \(2\)，求 \(a\)。

特征值之积 = 行列式：\(0\cdot2=|A|=a^2-1\Rightarrow a=\pm1\)。用迹检验：\(a+a=0+2\Rightarrow a=1\)。故 \(a=1\)（\(a=-1\) 时特征值为 \(0,{-2}\)，舍去）。点评：两个方程一般只需一个定 \(a\)，但必须用第二个方程检验——出题人常在这里设坑。

拓展 · 可能考考前加分

① 特征值速查表（同一特征向量 \(\xi\)，全部直接迁移）：\(kA\to k\lambda\)，\(A^m\to\lambda^m\)，\(f(A)\to f(\lambda)\)，\(A^{-1}\to\lambda^{-1}\)（\(A\) 可逆），\(A^*\to|A|/\lambda\)，\(A^{\top}\) 与 \(A\) 特征多项式相同，\(A+kE\to\lambda+k\)。证明核心一句话：\(A\xi=\lambda\xi\) 两边作用 \(A\) 的多项式并归纳。

② 不同特征值的特征向量线性无关（递推证明）：设 \(\sum k_i\xi_i=0\)，两边用 \(A-\lambda_rE\) 作用，除 \(\xi_r\) 外各项系数变为 \(k_i(\lambda_i-\lambda_r)\)，由归纳假设 \(k_i(\lambda_i-\lambda_r)=0\)，又 \(\lambda_i\ne\lambda_r\)，得 \(k_i=0\)，再回代得 \(k_r=0\)。

③ \(|A|=0\iff 0\) 是 \(A\) 的特征值：\(f(0)=|A|\)，一行搞定，连接第 1 篇与第 3 篇的桥梁。
