4.2 正定二次型

定义与等价条件定义

若对任意 \(x\ne0\) 都有 \(f=x^{\top}Ax>0\)，称二次型（或对称矩阵 \(A\)）正定。

$$\text{正定}\iff\begin{cases}\text{(1) 特征值全为正}\\ \text{(2) 各阶顺序主子式全为正}\\ \text{(3) 正惯性指数 } p=n\\ \text{(4) 存在可逆 } C\ \text{使 } A=C^{\top}C\end{cases}$$
$$\text{负定}\iff\begin{cases}\text{特征值全为负}\\ \text{奇数阶主子式为负、偶数阶主子式为正}\end{cases}\qquad \text{半正定：} f\ge0\ \text{且存在 } x\ne0\ \text{使 } f=0$$
证明正定的四个等价条件（逐条论证）

② 各阶顺序主子式全正（核心定理）：对 \(n\) 作数学归纳。\(n=1\) 显然。由 \(A\) 正定知 \(a_{11}=f(e_1)>0\)，用 \(a_{11}\) 消去第一行第一列的其他元素：\(f=(x_1+\cdots)^2+\)（\(n-1\) 元二次型 \(g\)），\(A\) 正定 ⟺ \(g\) 正定，而 \(g\) 的顺序主子式正是 \(A\) 的 \(2\sim n\) 阶主子式，归纳推进。反向：主子式全正时按上述过程"逐层配方"得 \(f\) 是平方和（系数全正），故正定。

① 特征值全正：正交变换 \(x=Qy\) 下 \(f=\sum\lambda_iy_i^2\)（合同不改变正负性），对任意 \(x\ne0\) 有 \(y\ne0\)，\(f>0\iff\) 每个 \(\lambda_i>0\)。

③ \(p=n\)：合同变换保持正负惯性指数（惯性定理），规范形全平方项为正即 \(p=n\)。

④ \(A=C^{\top}C\)：若正定，正交对角化 \(A=Q\Lambda Q^{\top}\)，取 \(C=\Lambda^{1/2}Q^{\top}\)（特征值全正故开方有意义）；反之 \(f=x^{\top}C^{\top}Cx=\|Cx\|^2>0\)（\(x\ne0\Rightarrow Cx\ne0\)）。

高频考点 数字矩阵判正定首选顺序主子式法（快）；抽象矩阵用特征值（配合 3.4 的迹/行列式公式）。必背反例提示：主对角线只要出现 \(\le0\) 的元素，或顺序主子式链上第一个负数出现，立即判非正定——可用于快速排除选项。

正定矩阵的性质定理

  • \(A\) 正定 ⇒ \(A^k,\ kA\ (k>0),\ A^{-1},\ A^*\) 都正定。
  • \(A,B\) 正定 ⇒ \(A+B\) 正定、\(\begin{pmatrix}A&\\&B\end{pmatrix}\) 正定；但 \(AB\) 不一定正定（甚至不对称）。
  • \(A\) 正定 ⇒ 主对角元 \(a_{ii}>0\)，\(|A|>0\)。
  • \(A^2\) 正定推不出 \(A\) 正定（反例 \(A=\operatorname{diag}(-1,-2)\)，\(A^2\) 正定）；但 \(A^3\) 正定可推出 \(A\) 正定（奇次幂）。
  • 正定矩阵的特征值全正，因此 \(\operatorname{tr}(A)>0\)、\(|A|>0\)（可用作快速否定）。
证明正定矩阵的运算封闭性

\(kA\ (k>0)\) 正定：\(x^{\top}kAx=k\,x^{\top}Ax>0\)。\(k<0\) 时负定。

\(A^{-1}\) 正定：特征值取倒数仍全正；或令 \(y=A^{-1}x\ne0\)，\(x^{\top}A^{-1}x=(Ay)^{\top}A^{-1}(Ay)=y^{\top}Ay>0\)。

\(A^{*}\) 正定：\(A^{*}=|A|A^{-1}\)，\( |A|>0\)（正定推论）乘以正定的 \(A^{-1}\)。

\(A+B\) 正定：\(x^{\top}(A+B)x=x^{\top}Ax+x^{\top}Bx>0\ for\ x\ne0\)。

\(AB\) 不一定：\(AB\) 未必对称（\((AB)^{\top}=BA\)），而正定的前提是对称——直接失去资格。

例 29顺序主子式法判正定

判断 \(f=5x_1^2+x_2^2+5x_3^2+4x_1x_2-8x_1x_3-4x_2x_3\) 是否正定。

$$A=\begin{pmatrix}5&2&-4\\2&1&-2\\-4&-2&5\end{pmatrix},\qquad \Delta_1=5>0,\quad \Delta_2=\begin{vmatrix}5&2\\2&1\end{vmatrix}=1>0$$

按第 1 行展开计算 \(\Delta_3=|A|\)（三个二阶主子式分别为 \(1,\ 2,\ 0\)）：

$$\Delta_3=5\cdot1-2\cdot2+(-4)\cdot0=1>0$$

三个顺序主子式全正 ⇒ 正定。点评：写矩阵时交叉项系数对半拆（\(4x_1x_2\to2,2\)；\(-8x_1x_3\to-4,-4\)；\(-4x_2x_3\to-2,-2\)），拆错则全题报废。

例 30含参数正定性讨论

\(t\) 取何值时，\(f=x_1^2+x_2^2+2x_3^2+2tx_1x_2+2x_1x_3\) 正定？

$$A=\begin{pmatrix}1&t&1\\t&1&0\\1&0&2\end{pmatrix},\qquad \Delta_1=1,\ \Delta_2=1-t^2,\ \Delta_3=|A|$$

计算 \(|A|=2(1-t^2)-t(2t)+1(0-1)\)?——展开：\(|A|=1(2-0)-t(2t-0)+1(0-1)=2-2t^2-1=1-2t^2\)。正定要求：

$$1-t^2>0\ \text{且}\ 1-2t^2>0\ \Longrightarrow\ -\frac{1}{\sqrt2}<t<\frac{1}{\sqrt2}$$

点评：含参数正定 = 逐个主子式列不等式求交集；务必按阶数顺序逐个写全，漏一个就是全错。

拓展 · 可能考考前加分

① 正定 ⟹ 主对角元全正（小证明）：取 \(x=e_i\)，\(a_{ii}=e_i^{\top}Ae_i>0\)。注意只是必要条件：对角元全正不能反推正定（如 \(\begin{pmatrix}1&10\\10&1\end{pmatrix}\) 不正定）。

② \(A^{\top}A\) 半正定，列满秩时正定：\(x^{\top}A^{\top}Ax=\|Ax\|^2\ge0\)；\(A\) 列满秩时 \(Ax\ne0\)（\(x\ne0\)），故严格大于零。这是构造半正定/正定矩阵的标准手法。

③ 正定矩阵的家族保持：\(A\) 正定 ⟹ \(A^{-1}\)（特征值 \(1/\lambda>0\)）、\(A^*\)（\(|A|/\lambda>0\)）、\(A^m\)（\(\lambda^m>0\)）都正定；但 \(A+B\) 正定需要 \(A,B\) 各自正定（半正定 + 正定也行），半正定 + 半正定不一定正定。

拓展 · 常用技巧技巧归纳

① 正定充要条件全家桶（任一即可）：顺序主子式全正；特征值全正；正惯性指数 \(=n\)；与 \(E\) 合同；存在可逆 \(C\) 使 \(A=C^{\top}C\)。

② 顺序主子式必须左上角逐阶：\(\Delta_1,\Delta_2,\dots,\Delta_n\) 依次取左上角 \(k\) 阶子式——位置取错是计算题最常见失误。

③ 含参正定套路：联立 \(\Delta_1>0,\Delta_2>0,\Delta_3>0\) 解公共区间，千万别只验 \(|A|>0\)。

④ 必要条件当快筛：正定 ⟹ \(a_{ii}>0\)、\(\operatorname{tr}A>0\)、\(|A|>0\)；对角元有非正的直接判"不正定"，省一轮完整计算。
