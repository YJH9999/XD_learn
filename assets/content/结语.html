结语

线性代数是一门"工具语法"课程：概念环环相扣，计算题型固定。本站的内容组织遵循三个原则——

  • 因果链组织：矩阵 → 秩 → 向量 → 相似 → 二次型，任何一个概念卡壳时沿因果链找源头；
  • 套路优先：每个高频题型都给出"破题第一眼"与固定流程（含参讨论两步走、对角化判定三部曲、正交化全流程）；
  • 易错前置：所有易错点在正文中就地用朱砂标注，并在附录 B 汇总成清单。

推荐的使用姿势：通读正文 → 收藏薄弱节（标题旁 ★）→ 冲刺模式筛选复习 → 备考中心随机组卷自测 → 考前过一遍 0.2 速查与附录 B。

本站内容参考了学校教材《线性代数（第 2 版）》的章节体系、《线性代数学习指导》的典型例题结构，以及公开的知识点整理资料，例题均经过独立验算。发现错误欢迎通过 GitHub 仓库 issue 反馈。
