# 线性代数题库转录规范（所有转录子代理必读）

## 任务
把指定 PNG 页面上的**每一道题**（题干 + 答案 + 解答）转录为结构化 JSON 条目，写入指定输出文件。不许遗漏任何题目；不许跳过没有答案的题（没有就自己写解答）。

## 输出格式
输出一个 JSON 数组（UTF-8，无 BOM），每个元素一道题：

```json
{
  "src": "期末2017A卷",        // 来源卷名/章节名，按分配给你的命名
  "srcNo": "解答3",            // 原卷题号（例3、同步练习5、解答2 等）
  "ty": "solve",               // judge | choice | blank | solve | proof
  "ch": 3,                     // 章节: 1=行列式/矩阵/方程组, 2=向量(线性相关/秩/解结构), 3=特征值/相似/对角化/正交, 4=二次型
  "kp": "特征值与行列式",       // 6-10 字考点
  "diff": 2,                   // 1易 2中 3难
  "score": 12,                 // 原卷分值；无分值信息填 8
  "q": "题干，KaTeX 公式",
  "opts": ["\\(A\\) 选项内容", "...", "...", "..."],   // 仅 choice 需要，4 个选项
  "ans": "最终答案（judge 填 √ 或 ×；choice 填正确项索引 0/1/2/3；其余填答案表达式）",
  "sol": "完整解答过程，HTML 片段"
}
```

- ty 判定：判断题→judge（ans 用 "√"/"×"）；选择题→choice（ans 用 0/1/2/3 指向 opts 下标）；填空题→blank；解答/计算题→solve；证明题→proof。若原卷题型不明，按内容判定。
- 填空题题干里的空写 `\\underline{\\hspace{2em}}`（大空用 3em/4em）。

## sol 的 HTML 规则（严格遵守）
- sol 是 HTML 片段：段落用 `<p>...</p>`，行间公式用 `<div class="fml">$$...$$</div>`，**开闭标签必须配对**。
- 解答要完整：有步骤、有关键公式、结尾可加一句方法点评。
- 若原页只有答案没有过程：由答案反推写出简洁完整的过程。

## KaTeX 与转义规则（最容易出错，逐条遵守）
1. 行内公式定界符 `\\(` 和 `\\)`；行间 `$$...$$`（在 fml div 内）。
2. **JSON 里所有 LaTeX 反斜杠都要双写**：`\\(A^{\\top}\\)`、`\\begin{pmatrix}`、`\\lambda`。JSON 解析后应为单反斜杠的 LaTeX 字符串。
3. 矩阵写法：`\\(\\begin{pmatrix}1&2\\\\3&4\\end{pmatrix}\\)`（行分隔符 `\\\\`）。
4. **数学模式内绝对不允许出现半角 `<` 字符后跟字母**：如 R(A)<n 必须写成 `R(A)&lt;n`；纯数字比较如 `n&lt;5` 同理全部用 `&lt;`。`>` 不用转义。
5. 数学模式内不许出现全角字符（（）、，、；等），标点一律半角。中文写在数学模式外。
6. 上下标：`x^{2}`、`A^{\\top}`、`\\eta_1`。常用宏：`\\R` 表示实数域。
7. 特征值/行列式竖线：`\\begin{vmatrix}...\\end{vmatrix}`。

## 去重
同一批里多份卷子出现**完全相同**的题：只转录一条，src 写成 `期末2017A卷/2018A卷` 这样合并。不同卷子上参数略有差异的题不算重复，分开转录。

## 质量自查（写完必须执行）
```
python -m json.tool 输出文件.json > /dev/null
```
必须通过。再自查：每条 sol 的 `<p>`/`<div>` 配对；数学模式内无半角 `<字母`；无全角标点混入公式。

## 其他
- 页面模糊或看不清的地方：尽力辨认，拿不准的数值在 kp 后不标注，但绝不要编造题目。
- 评分标准/参考答案卷子上的题目若与试卷题干重复，仅用于补全 sol。
- 一页上若有"得分""装订线"等无关内容，忽略之。
